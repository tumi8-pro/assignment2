# Discover Lesotho

A responsive five-page tourism website concept for the BIWD2110 Web Design Assignment 2.

## Pages

- `index.html` — homepage and featured destinations
- `about.html` — Lesotho and Basotho culture
- `destinations.html` — destination cards with search and category filters
- `gallery.html` — responsive photo gallery with a Bootstrap lightbox modal
- `contact.html` — trip enquiry and contact forms

## Features

- Semantic HTML5 landmarks and responsive Bootstrap 5 layout/components
- Custom CSS theme, responsive grid, hover states, and light/dark mode
- Destination search and category filters, plus accommodation and activity information
- Gallery modal with previous/next controls and keyboard arrow navigation
- Two client-side validated forms that save enquiries in browser storage, plus a validated newsletter form
- `localStorage` persistence for theme preference and newsletter demo opt-in
- Accessible labels, skip link, keyboard focus styles, and descriptive image alt text

## Run locally

Open `index.html` in a browser. Bootstrap, Google Fonts, and the sample photography load from external CDNs, so those assets require an internet connection. Enquiry forms validate and save submissions in the current browser only; no server or email service is connected. Replace the sample `hello@discoverlesotho.example` contact address and connect a backend before publishing for real enquiries.
